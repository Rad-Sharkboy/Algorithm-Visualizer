# 🪐 Algo Studio v2.1.2 — Orbit

Playback gets its own little kinetic instrument.

- A faceted shell, layered reflections, and an iridescent rim surround a morphing play/pause core.
- Two luminous particles orbit during playback, then settle when paused. The control offers Run, Pause, Resume, and Replay with a clear state label.
- Reflections follow the pointer; pressing the surface adds depth and a ripple.
- Dark and Light each have their own palette. System mode continues to follow the Windows app theme.
- Keyboard focus is visible; Space and Enter activate the control. Reduced motion freezes decorative effects. Hiding, disabling, or destroying the control cancels its animation timer.
- The README demo shows the new dial, pause/resume, and both themes.

The app still runs on the Python standard library: no external fonts, image assets, shaders, or pip dependencies.

## 🎮 Run

Download **Source code (zip)** from Assets and extract it. Keep the Python files together and run:

```powershell
py PROJECT.py
```

On macOS or Linux, use `python3 PROJECT.py`. Requires Python 3.10+, Tkinter, and a graphical desktop.

## 📦 Build a single Python file

```bash
python3 tools/build_release.py --version 2.1.2
python3 dist/Algo-Studio-v2.1.2.py
```

On Windows, use `py` in place of `python3`. The build also writes `dist/SHA256SUMS`.
