# ✨ Algo Studio v2.1.1 — Fresh Moves

A small update with clearer sorting and searching steps.

- **Bubble, Selection, Insertion, Shell, and Comb Sort** use indexed loops, temporary-variable swaps, insertion shifts, halving Shell gaps, and Comb's 1.3 shrink factor.
- **Quick Sort** recursively partitions with a last-element pivot and inward scans. **Merge Sort** recursively combines two temporary arrays. **Radix Sort** uses digit counts, cumulative totals, and a stable output pass.
- **Binary and Interpolation Search** now stop at the match they encounter. Linear Search still returns the first match.
- Guides, highlighted steps, and operation counts match the updated implementations. Selection's two array assignments count even when the minimum is already in place.

Negative integers, duplicates, empty inputs, and single values remain supported. Quick Sort's scans are bounded and advance after swaps; Radix Sort advances digit places by multiplying by ten. The app uses only the Python standard library.

## 🎮 Run the update

Download **Source code (zip)** from Assets and extract it. Keep the Python files together, then run from the extracted folder:

```powershell
py PROJECT.py
```

On macOS or Linux:

```bash
python3 PROJECT.py
```

Requires Python 3.10+, Tkinter, and a graphical desktop. The single-file Python bundle is built locally; a standalone attachment is pending upload access.

## 📦 Build the single-file version

```bash
python3 tools/build_release.py --version 2.1.1
python3 dist/Algo-Studio-v2.1.1.py
```

On Windows, use `py` in place of `python3`. The deterministic build also writes `dist/SHA256SUMS`.
