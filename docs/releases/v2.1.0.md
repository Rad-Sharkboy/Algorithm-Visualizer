# 🌓 Algo Studio v2.1.0 — Daylight & Glass

A fresh coat of light, a little liquid glass, and type that feels at home on your desktop.

## ✨ What's new

- **Light, Dark, and System themes** across the entire studio, including charts, inputs, dropdowns, tooltips, and open algorithm guides.
- **Live Windows theme matching:** System reads the app color preference every two seconds. Manual choices override it. Other platforms and unavailable preferences fall back to Dark.
- **Glass-inspired playback:** rounded gradients, a moving reflection, a press ripple, and a play/pause icon that morphs between states.
- **A matching Reduced motion pill:** decorative effects stop immediately; algorithms still run normally.
- **Native font priorities:** Segoe UI Variable / Segoe UI, SF Pro Text / Helvetica Neue, Noto Sans, and installed coding fonts. No bundled fonts or pip dependencies.
- **Theme changes preserve your place:** input, focus, algorithm progress, and scheduled animation keep working.
- **Updated animated README footage** showing both palettes and the new controls.

The glass effect is drawn in Tkinter; it does not blur other windows. Windows detection is read-only and does not change system settings.

## 🎮 Run it

Download **`Algo-Studio-v2.1.0.py`** from the release's Assets. It contains all six application modules in one readable file.

```powershell
# Windows
py Algo-Studio-v2.1.0.py
```

```bash
# macOS / Linux
python3 Algo-Studio-v2.1.0.py
```

Requires **Python 3.10+**, **Tkinter**, and a graphical desktop. Like V1 and v2.0.0, this is a Python runnable, not a Windows `.exe`. Check Tkinter with `py -m tkinter` or `python3 -m tkinter`.

## 🔎 Verify or rebuild

The accompanying `SHA256SUMS` contains the runnable's SHA-256 digest. Compare it using `Get-FileHash .\Algo-Studio-v2.1.0.py -Algorithm SHA256` on Windows, `shasum -a 256 Algo-Studio-v2.1.0.py` on macOS, or `sha256sum -c SHA256SUMS` on Linux.

From the source at tag `v2.1.0`, rebuild with:

```bash
python3 tools/build_release.py --version 2.1.0
python3 dist/Algo-Studio-v2.1.0.py --version
```

The deterministic standard-library build writes the runnable and checksum into `dist/`. All **55 local checks** passed on Python 3.12 and 3.13, including the isolated release bundle on 3.13. They cover all algorithms, live theme changes, simulated Windows registry preferences, keyboard and mouse activation, reduced motion, resizing, and timer cleanup. Native Windows/macOS desktops were not available for direct verification.
