# Algo Studio v2.1.3 — Frost

A refined set of playback controls and clearer documentation.

- A rounded, frosted Run button replaces the orbital dial. Soft shading, smooth icon edges, and a subtle press transition keep the control legible in both themes.
- Animation speed and array size now use rounded tracks with blue fills and raised capsule handles. Click the track or drag the handle; dragging preserves the initial grab position and respects each slider's limits.
- Focused sliders support arrow keys, Page Up / Page Down, and Home / End. These adjustments do not trigger the application's playback shortcuts.
- Theme changes preserve slider values and playback state. Reduced motion disables transitions, and hidden or destroyed controls cancel their pending callbacks.
- README wording is more concise and professional. The original header is retained, and the demo remains at the top with updated footage.

The app requires no pip packages, external fonts, or runtime image files.

## Run

Download **Source code (zip)** from Assets and extract it. Keep the Python files together, then run:

```powershell
py PROJECT.py
```

On macOS or Linux, use `python3 PROJECT.py`. Requires Python 3.10+, Tkinter, and a graphical desktop.

## Single-file build

```bash
python3 tools/build_release.py --version 2.1.3
python3 dist/Algo-Studio-v2.1.3.py
```

On Windows, use `py` in place of `python3`. The build also writes `dist/SHA256SUMS`.
