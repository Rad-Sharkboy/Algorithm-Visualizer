# Algo Studio v3.0.0 — In Full Color

Same algorithms. A whole new instrument. 🎛️

- **A console with character:** glowing signal columns, arcing swaps, animated counters, and a completion wave.
- **Five moods, one memory:** Phosphor, Paper, Red, Maroon, and Purple. Your chosen palette — or System mode — returns next time.
- **Smoother controls:** refined slider handles, drawn playback icons, and less unnecessary rendering work.
- **A signature touch:** click “Made by Radsharkboy” in the footer to visit the project.
- **Ready for another run:** keyboard controls, reduced motion, input validation, and cancellation checked locally. All 13 sorting/searching implementations are unchanged.

## Run

**[Download the portable build ZIP](https://github.com/Rad-Sharkboy/Algorithm-Visualizer/raw/refs/tags/v3.0.0/builds/Algo-Studio-v3.0.0.zip)** · [Single Python file](https://github.com/Rad-Sharkboy/Algorithm-Visualizer/raw/refs/tags/v3.0.0/builds/Algo-Studio-v3.0.0.py) · [SHA-256 checksums](https://github.com/Rad-Sharkboy/Algorithm-Visualizer/raw/refs/tags/v3.0.0/builds/SHA256SUMS)

Extract the ZIP, then on Windows:

```powershell
py Algo-Studio-v3.0.0.py
```

On macOS/Linux, use `python3 Algo-Studio-v3.0.0.py`. Requires Python 3.10+, Tkinter, and a graphical desktop. No pip dependencies or external font/image files. **SHA256SUMS** is included for verification. The build is stored with the version tag and linked above because GitHub rejected release-attachment uploads with the available credentials.

Prefer the source? Extract **Source code (zip)** and run `py PROJECT.py` or `python3 PROJECT.py`.
