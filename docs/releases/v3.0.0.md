# Algo Studio v3.0.0 — In Full Color

Same algorithms. A whole new instrument. 🎛️

- **A console with character:** glowing signal columns, arcing swaps, animated counters, and a completion wave.
- **Five moods, one memory:** Phosphor, Paper, Red, Maroon, and Purple. Your chosen palette — or System mode — returns next time.
- **Smoother controls:** refined slider handles, drawn playback icons, and less unnecessary rendering work.
- **A signature touch:** click “Made by Radsharkboy” in the footer to visit the project.
- **Ready for another run:** keyboard controls, reduced motion, input validation, and cancellation checked locally. All 13 sorting/searching implementations are unchanged.

## Run

Download **Algo-Studio-v3.0.0.py** from Assets. On Windows:

```powershell
py Algo-Studio-v3.0.0.py
```

On macOS/Linux, use `python3 Algo-Studio-v3.0.0.py`. Requires Python 3.10+, Tkinter, and a graphical desktop. No pip dependencies or external font/image files. **SHA256SUMS** is included for verification.

Prefer the source? Extract **Source code (zip)** and run `py PROJECT.py` or `python3 PROJECT.py`.
