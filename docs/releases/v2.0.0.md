# ⚡ Algo Studio v2.0.0 — Algorithms in Motion

The visualizer grew up. Thirteen algorithms, a fresh dark studio, and bars with moves. 🪄

## 📦 Pick up the runnable

Download **`Algo-Studio-v2.0.0.py`** from this release's **Assets**. All application code is bundled into that single file; you do not need to clone the repository or download its helper modules.

| Your desktop | Start the show |
| :--- | :--- |
| Windows | `py Algo-Studio-v2.0.0.py` |
| macOS / Linux | `python3 Algo-Studio-v2.0.0.py` |

Requires **Python 3.10+**, **Tkinter**, and a graphical desktop. There are **zero pip dependencies**. Run `python3 -m tkinter` (Windows: `py -m tkinter`) to check your Python installation; a small demo window should open. If Tkinter is missing, install Python with Tcl/Tk support or your operating system's Python Tk package.

**V1 shipped as `PROJECT.py` (“Initial Release (Python File)”). V2 keeps that runnable Python format.** This download requires Python; it is not a Windows `.exe`.

## 🎆 What's inside

- **The full lineup:** Bubble, Selection, Insertion, Shell, Comb, Merge, Quick, Heap, Counting, and Radix Sort; Linear, Binary, and Interpolation Search.
- **Motion with meaning:** curved swaps, smooth writes, glowing comparisons, and a completion sweep with sparkles. Reduced motion is available too.
- **You control the pace:** run, pause, resume, step, stop, reset, replay, and change the speed during a run.
- **Bring your own data:** signed integers, zeros, duplicates, four presets, and editable search targets.
- **Follow every decision:** highlighted pseudocode, algorithm guides, operation counters, value tooltips, and keyboard controls.
- **A playful README:** real animated app footage, algorithm personalities, and mini challenges. ✨

Binary and Interpolation Search sort a copy before searching. All searches report the first matching index; Reset restores your original input.

## 🔎 Verify your download

`SHA256SUMS` contains the SHA-256 digest of the runnable. Compare it with:

```powershell
# Windows PowerShell
Get-FileHash .\Algo-Studio-v2.0.0.py -Algorithm SHA256
```

```bash
# macOS
shasum -a 256 Algo-Studio-v2.0.0.py
# Linux (download SHA256SUMS alongside the runnable)
sha256sum -c SHA256SUMS
```

## 🛠️ Rebuild from source

From the repository at tag `v2.0.0`:

```bash
python3 tools/build_release.py --version 2.0.0
python3 dist/Algo-Studio-v2.0.0.py --version
```

The standard-library builder produces the runnable and checksum in `dist/`. The build is deterministic: identical source and version produce identical bytes. GitHub's automatic source archives contain the modular development project; the named `.py` asset is the ready-to-run bundle.

**Local verification:** all 43 algorithm, GUI, input, and animation checks passed against the isolated bundle on Linux with Python 3.12 and 3.13. The standalone entry point also opened and closed its real Tk window successfully. Windows and macOS were not available for direct verification.
